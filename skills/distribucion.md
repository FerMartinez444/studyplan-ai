# Distribucion del estudio

Objetivo: organizar las sesiones academicas.

Reglas:
- Respetar las horas disponibles de cada dia.
- No programar estudio en la fecha del examen.
- Incluir teoria, ejercicios y repasos.
- Reservar aproximadamente el 20 % del tiempo para repaso y autoevaluacion.
- Evitar sesiones demasiado extensas.
- Informar si el plan resulta poco realista.
